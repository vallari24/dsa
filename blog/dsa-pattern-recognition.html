The 3-Question Script

Run this on every array/string problem — out loud. Interviewers reward hearing it.

Q1
Can I restate the answer as a formula? max / min / count / sum … over what, exactly? Saying “the answer is max(prices[j] − prices[i]) for j > i” is already half the solve.
Q2
Can I decompose it per index? “What is the answer at position i alone?” Water above bar i. Profit if I sell on day i. Longest window ending at i.
Q3
What does position i need to know? This is where the pattern names itself:
nothing beyond itself
one pass
something from its LEFT only
running variable
something from BOTH sides
prefix/suffix → two pointers
nearest BIGGER / SMALLER element
monotonic stack
best over a contiguous window
sliding window
“have I seen this before?”
hash map

Read the constraints first — they whisper the answer

The size of n tells you the complexity the interviewer intends. Work backwards from it.

n ≤ 20
O(2ⁿ) backtracking · bitmask
n ≤ 1,000
O(n²) 2D DP · nested loops
n ≤ 100,000
O(n log n) sort · heap · binary search
n ≤ 10⁶
O(n) hashmap · window · prefix · mono-stack
n ≥ 10⁹
O(log n) binary search — nothing else survives

Bonus tells: “O(1) space” → two pointers, running vars, bit tricks · values in range 1..n → cyclic sort / index-as-hash / XOR.

Two Pointers

sortedpair / triplet sumpalindromecontainerin place

Sorted means moving a pointer changes the sum in a known direction — I never need to look back.

l, r = 0, len(a) - 1
while l < r:
    if a[l] + a[r] == target: return [l, r]
    elif a[l] + a[r] < target: l += 1
    else: r -= 1

Sliding Window

longest / shortest substringcontiguous subarrayat most Kconsecutive

The answer is a contiguous run, and adding elements only makes the condition worse — so slide, don’t restart.

l = 0
for r in range(n):
    add(a[r])                          # expand
    while invalid(): remove(a[l]); l += 1   # shrink
    best = max(best, r - l + 1)

Trap: if negatives can fix a broken window (subarray sums with negative numbers), sliding window fails — use prefix sum + hashmap instead.

Prefix / Suffix Precompute

range sumproduct except selfmax to my left / rightbetween i and j

Every index asks the same question about everything before or after it — answer them all in one pre-pass.

prefix[i] = prefix[i-1] + a[i]        # sum(i..j) = prefix[j] - prefix[i-1]
leftmax[i]  = max(leftmax[i-1],  h[i])   # → pass
rightmax[i] = max(rightmax[i+1], h[i])   # ← pass

Monotonic Stack

next greater / smallerdays until warmerhistogramstock span

Each element pops everyone it answers, then waits its own turn. Everyone is pushed and popped once — O(n).

stack = []                            # indices, values decreasing
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        j = stack.pop(); ans[j] = i - j
    stack.append(i)

Heap / Priority Queue

top KKth largestK closestmerge K listsmedian of stream

I don’t need everything sorted — I only need the best K, maintained cheaply.

heap = nums[:k]; heapq.heapify(heap)
for x in nums[k:]:
    if x > heap[0]: heapq.heapreplace(heap, x)
return heap[0]                        # Kth largest

Tie-breakers: one-shot & average-case fine → quickselect · values in a small range → bucket sort (the O(n) trick in Top K Frequent) · “median of a stream” → two heaps.

Trees: DFS vs BFS

max depth / diameterpath sumlevel ordernearestvalidate BSTLCA

DFS: “if my left child told me X and my right child told me Y, my answer is…” — BFS: process level by level.

def depth(node):                       # the DFS sentence, in code
    if not node: return 0
    return 1 + max(depth(node.left), depth(node.right))

Backtracking

ALL subsets / permutationsall valid boardsn ≤ ~20

They want the list of every answer, not a count — so I walk the whole decision tree: choose, recurse, un-choose.

def backtrack(path, i):
    if i == n: ans.append(path[:]); return
    path.append(nums[i]); backtrack(path, i+1)   # take
    path.pop();           backtrack(path, i+1)   # skip — the UNDO is the pattern

Sorting — steal the algorithm, skip the sort

No interviewer asks you to implement mergesort. But the machinery inside each sort is a reusable pattern that solves famous problems on its own. Learn the sorts as a toolbox of moves, not as trivia.

Quicksort’s partition

kth largest / smallest3 distinct valuesin-place regions

One pass puts the pivot in its FINAL position and splits the rest — recurse only into the half you care about, and O(n log n) becomes O(n).

def quickselect(lo, hi, k):          # kth smallest
    p = partition(lo, hi)            # pivot lands at its final index
    if p == k: return a[p]
    return quickselect(p+1, hi, k) if p < k else quickselect(lo, p-1, k)

Cyclic sort — every value has a home

values exactly 1..n (or 0..n)find missing / duplicateO(1) space demanded

Value v belongs at index v−1 — keep swapping each element home; the first squatter you find afterwards is the answer.

i = 0
while i < n:
    home = a[i] - 1
    if 0 <= home < n and a[home] != a[i]:
        a[i], a[home] = a[home], a[i]     # send it home, stay put
    else:
        i += 1

Two more sorts hide inside patterns you already know: heapsort is just the heap pattern run to completion (Top K, Kth in a Stream, Last Stone Weight), and patience sorting is the O(n log n) trick behind Longest Increasing Subsequence. And remember the quietest cue of all: “sort first” unlocks whole families — 3Sum, Merge Intervals, Meeting Rooms, Non-Overlapping Intervals, Car Fleet, Hand of Straights all start with one sort().

In the room: the 5-step loop

1

Restate + constraints. “n up to 10⁵, so I’m aiming for O(n log n) or better.” You just showed seniority.

2

Say the brute force in one sentence. It’s your safety net — and the pattern hides in its inefficiency: “the inner loop re-searches for X” → hashmap / stack / window replaces it.

3

Run the 3-question script out loud. “What does each index need to know?” Interviewers reward hearing the reasoning.

4

Name the pattern, state complexity, then code. The skeleton is muscle memory if you’ve drilled it.

5

Test tiny + one edge case. Empty, size 1, all-same, negatives.
